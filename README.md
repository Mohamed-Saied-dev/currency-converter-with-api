# Currency Converter (Simple Web App)

This is a simple project I made to practice using APIs with JavaScript.

The app lets you convert from one currency to another. You choose the "from" and "to" currencies, enter the amount, and it gets the exchange rate using the [CurrencyFreaks](https://currencyfreaks.com/) API.

## Quick Features:
- Pure JavaScript (no frameworks or libraries).
- Gets real-time exchange rates from the internet.
- If the API doesn’t work (like free quota ends), it uses default rates so the app doesn't break.
- Simple and easy-to-use UI.

## Notes:
- You’ll need an API key from CurrencyFreaks (free).
- This project is for learning only, not for real money conversions.
